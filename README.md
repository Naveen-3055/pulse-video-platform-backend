# Pulse Video Platform – Backend

Backend service for a role-based video moderation and streaming platform.
Built using Node.js, Express, MongoDB, and Socket.IO.

## Features
- JWT Authentication using HTTP-only cookies
- Role-Based Access Control (Viewer, Editor, Admin)
- Secure video upload using Multer
- Real-time upload status updates via Socket.IO
- Automated video status handling (Processing, Safe, Flagged)
- REST APIs for authentication and video management
- Protected routes based on user roles

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- Multer (file upload)
- Socket.IO (real-time updates)
